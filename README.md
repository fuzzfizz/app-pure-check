# PureCheck 🌿

An AI-powered cosmetic and skincare ingredient safety analyzer tailored for Thai consumers. **PureCheck** allows users to scan cosmetic barcodes, extract ingredient lists, and get personalized safety analysis matching their unique skin type, conditions, and allergy history using Gemini AI, Supabase Edge Functions (BFF Pattern), and automated Database Guardrails.

---

## ✨ Key Features & User Journeys

- **Journey A: Personalized Skin Profile**
  - 4-step onboarding stepper to configure:
    - **Skin Type:** Oily, Dry, Combination, Normal, Sensitive.
    - **Skin Conditions:** Eczema, Rosacea, Psoriasis, Acne-prone, or Pregnancy/Breastfeeding health flags.
    - **Allergen Registry:** Register known allergens with severity levels and reaction symptoms.
    - **Concerns & Avoidances:** Select concerns (Acne, Wrinkles, Pores) and preferences (e.g., avoid fragrance/alcohol).

- **Journey B: Smart Barcode Camera Scanner & INCI Entry**
  - Live camera barcode scanner powered by `mobile_scanner`.
  - Open Beauty Facts API fallback for unrecognized products.
  - **Tier 1 INCI Auto-Complete:** Real-time debounced ingredient suggestions powered by Supabase `pg_trgm` fuzzy matching.
  - **Tier 2 AI Pre-Clean ("Did You Mean...?"):** On submission, unrecognized ingredients are checked by Gemini AI to present interactive typo corrections before analysis.
  - Verify & edit details page to inspect parsed ingredients list.

- **Journey C: AI Safety Report & Health Guardrails**
  - **BFF Pattern (Backend for Frontend):** Route ingredient analysis securely through Supabase Edge Function `analyze-ingredients`, hiding `GEMINI_API_KEY` on the server.
  - **Database Guardrails:** Cross-checks products against a `hazardous_chemicals` blacklist DB table using smart regex word boundary matching and safe fatty alcohol exclusions.
  - **Traffic-Light Verdict:** Green (Safe), Yellow (Caution), Red (Allergen / Hazard Found).
  - **Health Disclaimer Banner:** Renders clear medical disclaimer banners on `ResultScreen` ("ผลลัพธ์นี้ประมวลผลโดย AI ควรปรึกษาแพทย์หรือผู้เชี่ยวชาญหากมีอาการแพ้รุนแรง").
  - **AI Analysis Summary:** Natural language explanations in Thai generated by Gemini AI.
  - **Interactive Breakdown:** Grouped list of ingredients (Safe / Caution / Danger) with toggleable functionality descriptions.

- **Journey D: Hybrid Product Submission & AI Admin Moderation Assistant**
  - **Hybrid Pending Review:** User-submitted products get instant personal AI analysis, while receiving `status = 'pending'` & `is_verified = false` to keep them hidden from general public search via RLS policies.
  - **AI Admin Moderation Dashboard (`/admin/review`):** Admin queue evaluating pending products with automated AI confidence scores (0-100%), visual traffic light badges (🟢 🟡 🔴), and 1-click batch auto-approval for safe products.

- **Journey E: Profile & Settings**
  - Update skin profile, manage allergen lists, view historical scan logs, and securely log out.

## 🛠️ Tech Stack & Architecture

- **Framework:** Flutter 3.44.1 / Dart 3.12.1
- **Architecture Pattern:** Clean Architecture with Repository Pattern (`ScanRepository`, `ScanRepositoryImpl`)
- **State Management:** Riverpod (`flutter_riverpod`)
- **Navigation:** `go_router` (enforcing auth redirect guards)
- **Backend & Auth:** Supabase (`supabase_flutter`, Row Level Security, Edge Functions)
- **Database Search Engine:** Supabase PostgreSQL with `pg_trgm` Trigram GIN indexing
- **AI Engine:** Google Generative AI / Gemini 1.5 Flash via Supabase Edge Function BFF
- **Design System:** Custom Material 3 theme using **Noto Sans Thai** (Google Fonts)
- **Localizations:** English and Thai bilingual support (ARB compiler via `flutter gen-l10n`)

## 🚀 Getting Started

### 1. Prerequisites

Ensure you have the Flutter SDK configured on your machine:

```bash
flutter doctor
```

### 2. Configure Environment Variables

1. Copy the template file:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and fill in your Supabase credentials:
   ```env
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_ANON_KEY=your_anon_key_here
   ```

### 3. Install Dependencies & Generate Code

Install package dependencies:

```bash
flutter pub get
```

Compile localization files:

```bash
flutter gen-l10n
```

### 4. Run Tests

Verify full unit and widget test suite:

```bash
flutter test
```

### 5. Run the Application

Start the development server on a connected mobile device or emulator:

```bash
flutter run
```
